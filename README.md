# Building-An-LLM-From-Scratch
Building An LLM From Scratch

## Acknowledgements

This project is inspired by [Vizuara](https://www.youtube.com/@Vizuara) and his educational content on building LLMs from scratch.  
I’m following along to understand the core concepts step by step, while also exploring areas where I can expand, experiment, and add my own implementations.

## Model Weights

The pretrained GPT-2 weights are **not included in this repository** because they are too large to store on GitHub.  
To download them yourself, simply run the `gpt_download3.py` script located in the `notebooks/` directory.  
This script will fetch the model files directly from OpenAI’s public storage.
